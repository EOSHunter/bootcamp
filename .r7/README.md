# R7 repository context: bootcamp

This is an archive of 2017 bootcamp work, rather than one deployable app. The default branch contains many separate front-end exercises, QA experiments, design files, and photos.

- `Front End/` contains individual projects including `dream-share-master/`, `project3/`, `project4/`, `vex/`, `learningcurve/`, and `Frontier-Layout/Frontier-Layout-Challenge/`. Each has its own entry point or package metadata; do not treat the root as one application.
- `Front End/vex/index.html` is a Vex-branded page. Its local `package.json` declares jQuery, Slick Carousel, and Foundation 5 and a Sass watch command. Other project folders have their own package files.
- `Front End/QA/` and `Front End/webdriverio-test/` contain browser-testing material.
- `Web Design:UI/` contains a Nike redesign and image/design assets. Its colon-containing names cannot be checked out on this Windows host, though Git can read them as tree objects.

These notes describe the default branch at `f769b1b1f8190601d7e277c4226244d62941c581`. There is no verified current deployment. See [bounded recent history](changes/2017-12.md).
